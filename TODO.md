# Leaf & Lore Outcomes

- [x] Responsive home page with an editorial bookshop layout and clear storefront navigation.
- [x] Featured-books presentation using realistic titles, authors, covers, prices, ratings, and summaries.
- [x] Browse-by-category sections for discovering books by genre or theme.
- [x] Search interaction for finding books by title, author, or keyword.
- [x] Filter and sorting controls for refining the visible book collection.
- [x] Book detail affordances with expanded descriptions, metadata, pricing, and purchase actions.
- [x] Client-side wishlist interactions with saved-state feedback.
- [x] Client-side shopping cart interactions with quantity updates, item removal, totals, and empty states.
- [x] Polished checkout preview with order summary and realistic form states, without live payment processing.
- [x] Managed server and MySQL database enabled for the project.
- [x] Drizzle schema and migration for the catalog, wishlist, cart, orders, and order item snapshots.
- [x] Typed tRPC procedures for catalog reads, persisted guest state, cart/wishlist mutations, and pending checkout orders.
- [x] React storefront hydrated from the backend with a browser session ID and server-side order total calculation.
